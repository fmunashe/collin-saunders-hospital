6Nginx Configuration

Create /etc/nginx/sites-available/hms:

server {
    listen 80;
    server_name hms.hospital.local;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name hms.hospital.local;
    root /var/www/hms/public;

    ssl_certificate     /etc/ssl/hms/fullchain.pem;
    ssl_certificate_key /etc/ssl/hms/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header Strict-Transport-Security "max-age=31536000" always;

    index index.php;
    charset utf-8;
    client_max_body_size 25M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 120;
    }

    location ~ /\.(?!well-known).* { deny all; }
}
sudo ln -s /etc/nginx/sites-available/hms /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

7PHP-FPM Tuning

Edit /etc/php/8.3/fpm/pool.d/www.conf — size the pool to server RAM (≈ 50 MB per worker):

pm = dynamic
pm.max_children = 40        ; ~2GB reserved for FPM on 16GB box
pm.start_servers = 8
pm.min_spare_servers = 6
pm.max_spare_servers = 12
pm.max_requests = 500

And /etc/php/8.3/fpm/php.ini:

memory_limit = 256M
upload_max_filesize = 25M
post_max_size = 25M
max_execution_time = 120
opcache.enable = 1
opcache.memory_consumption = 256
opcache.max_accelerated_files = 20000
opcache.validate_timestamps = 0   ; production: rely on deploy cache clears
sudo systemctl restart php8.3-fpm

8Redis Configuration

Edit /etc/redis/redis.conf:

maxmemory 2gb
maxmemory-policy allkeys-lru
requirepass <redis-password>
appendonly yes            ; durability for queued jobs
supervised systemd
sudo systemctl enable redis-server
sudo systemctl restart redis-server
Note: Use allkeys-lru only if Redis is shared for cache. If queue durability is critical, run a second Redis instance (or logical separation) for queues with noeviction so jobs are never dropped.

9Queue Workers & Horizon

Horizon manages Redis queue workers with auto-balancing and a metrics dashboard at /horizon. Install & publish:

composer require laravel/horizon
php artisan horizon:install
php artisan config:cache

Configure worker balancing in config/horizon.php:

'environments' => [
    'production' => [
        'supervisor-1' => [
            'connection' => 'redis',
            'queue' => ['default'],
            'balance' => 'auto',
            'minProcesses' => 1,
            'maxProcesses' => 10,
            'balanceMaxShift' => 1,
            'balanceCooldown' => 3,
            'tries' => 3,
            'timeout' => 120,
        ],
    ],
],
Horizon access: restrict the /horizon dashboard via the HorizonServiceProvider gate to admin users only.

10Supervisor Configuration

Supervisor keeps Horizon (and thus all workers) running and restarts it on failure or deploy. Create /etc/supervisor/conf.d/hms-horizon.conf:

[program:hms-horizon]
process_name=%(program_name)s
command=php /var/www/hms/artisan horizon
autostart=true
autorestart=true
user=www-data
redirect_stderr=true
stdout_logfile=/var/www/hms/storage/logs/horizon.log
stopwaitsecs=3600
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start hms-horizon

On each deploy, gracefully restart workers so they pick up new code:

php artisan horizon:terminate   # Supervisor auto-restarts Horizon

11Scheduler (Cron)

Add the Laravel scheduler to www-data's crontab for daily backups, expiry checks, and low-stock alerts:

sudo crontab -u www-data -e

# add:
* * * * * cd /var/www/hms && php artisan schedule:run >> /dev/null 2>&1

12TLS / SSL

For an internet-facing host use Let's Encrypt; for an internal LAN host use an internal CA or a self-signed certificate distributed to workstations.

# Let's Encrypt (internet-facing)
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d hms.hospital.local

npm ci && npm run build
