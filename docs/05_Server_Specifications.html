Disk type matters: use SSD/NVMe. Database and Redis performance degrade sharply on spinning disks. RAID-1 (mirroring) protects against single-disk failure.

5Operating System

  • Ubuntu Server 22.04 LTS or 24.04 LTS (64-bit) — long-term support, well-tested with the stack.
  • Alternative: Debian 12, RHEL/Rocky Linux 9.
  • 64-bit only. Kernel with up-to-date security patches.

7Environmental & Operational

  • Power: UPS with clean shutdown; generator backup recommended for a hospital.
  • Cooling: server room within manufacturer temperature range.
  • Network: wired Gigabit LAN, static IP, internal DNS entry (e.g. hms.hospital.local).
  • Firewall: expose only 443 (and 80 for redirect) to the LAN; SSH restricted to admin subnet.
  • Time sync: NTP enabled for accurate audit timestamps.
