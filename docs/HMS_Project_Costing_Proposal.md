## 9. Assumptions & Exclusions

### Assumptions
- Client provides timely access to subject matter experts for requirements
- Client provides test data and validation within 5 business days of each sprint demo
- Network infrastructure at the hospital is in place (LAN, internet)
- Maximum 2 rounds of revision per deliverable
- Working hours: Monday–Friday, 8 hours/day

### Exclusions
- Hardware procurement (PCs, printers, scanners, barcode readers)
- Third-party system integrations (NHIS, medical aid APIs) beyond basic structure
- Ongoing support & maintenance post go-live (quoted separately)
- Data migration from legacy systems (quoted separately based on assessment)
- End-user devices and peripherals
- Network infrastructure setup
